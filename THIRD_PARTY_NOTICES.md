# Third-party notices

pdf-tools is licensed under AGPL-3.0-only (see `LICENSE`). It ships the following third-party
software in its browser bundle. Each keeps its own license; the full texts are in the packages
under `node_modules/<name>/` and are included in release artifacts.

| Component | License | Used for |
| --- | --- | --- |
| [pdf-lib](https://github.com/Hopding/pdf-lib) | MIT | Creating and editing PDFs |
| [pdf.js / pdfjs-dist](https://github.com/mozilla/pdf.js) | Apache-2.0 | Thumbnails; its fonts, CMaps, ICC profiles and image decoders (OpenJPEG BSD-2, JBIG2 Apache-2.0, qcms MIT) are copied from the package; the scripting engine is excluded |
| [React, React DOM](https://github.com/facebook/react) | MIT | User interface |
| [fflate](https://github.com/101arrowz/fflate) | MIT | Zip downloads for multi-file results |
| [qpdf](https://github.com/qpdf/qpdf) via [@neslinesli93/qpdf-wasm](https://github.com/neslinesli93/qpdf-wasm) | Apache-2.0 (qpdf), ISC (wrapper) | Compress (object streams, Flate recompression); validation in tests; encryption tools (from M4) |
| [libheif-js](https://github.com/catdad-experiments/libheif-js) (libheif, libde265, dav1d) | LGPL-3.0 (libheif, libde265), BSD-2-Clause (dav1d) | Decoding HEIC/HEIF/AVIF images; shipped unmodified as a separate WASM file (ADR 0004) |

Development-only tools (Vite, Vitest, Playwright, ESLint, TypeScript and their dependencies) are
not shipped to users. CI checks every installed dependency against the license allowlist in
`scripts/check-licenses.ts`.

The fixture PDFs in `packages/core/fixtures/corpus` are synthetic, generated by
`packages/core/fixtures/generate.ts`, and covered by this project's license.

This file is updated whenever a shipped dependency is added (later milestones add
tesseract.js and its language data).
