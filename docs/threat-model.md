# Threat model (living copy of SPEC.md §6, with how each mitigation is implemented)

| Threat                                                                                              | Mitigation in this repository                                                                                                                                                                                                                                                                                                                                | Status                             |
| --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------- |
| Supply-chain compromise exfiltrates files                                                           | CSP `connect-src 'self'` (+ one optional analytics origin), `script-src 'self' 'wasm-unsafe-eval'`, `object-src 'none'`, `base-uri 'none'`, `form-action 'none'`, `frame-ancestors 'none'` from `apps/web/security-headers.ts`. Exact pins, lockfile, `minimumReleaseAge`, no install scripts, Renovate with manual review, audit, CodeQL, dependency review | Done (M1)                          |
| Exfiltration through same-origin requests (e.g. a POST to our own host that a compromised CDN logs) | e2e guard fails on any non-GET request and any body >1 KB                                                                                                                                                                                                                                                                                                    | Done (M1)                          |
| Malicious PDF executes code via pdf.js                                                              | pdf.js 6 has no eval path; CSP forbids eval anyway; we never load the scripting sandbox; rendering runs in pdf.js's worker                                                                                                                                                                                                                                   | Done (M2): data files self-hosted, quickjs not shipped, `maxImageSize` cap on previews |
| PDF bombs                                                                                           | Per-op timeout terminates the worker; page cap (10,000) in `loadPdf`; size cap 1 GB; nesting-bomb fixture tested                                                                                                                                                                                                                                             | Done (M1); fuzzing in M6           |
| Deploy hijack                                                                                       | Deploy only from signed tags via CI to a reviewed `production` environment; SHA256SUMS + SLSA provenance published per release                                                                                                                                                                                                                               | Configured (M1), owner must enable |
| XSS via filenames / metadata                                                                        | React text rendering only; ESLint rule bans `dangerouslySetInnerHTML`                                                                                                                                                                                                                                                                                        | Done (M1)                          |
| Weak password protection | AES-256 (R6) only via qpdf named options; random owner password when none is given; passwords stay in the worker and are never logged | Done (M4) |
| Redaction leaving hidden text                                                                       | v2                                                                                                                                                                                                                                                                                                                                                           | Not started                        |
| Signature misuse claims | Permanent note on the Sign tool: visual signature, not a certified or cryptographic e-signature | Done (M4) |
| Clickjacking                                                                                        | `frame-ancestors 'none'` and `X-Frame-Options: DENY`                                                                                                                                                                                                                                                                                                         | Done (M1)                          |
| Malicious image files (HEIC/AVIF via libheif, others via the browser) | Decoded only in the ops worker (timeout + terminate), 100-megapixel cap, typed errors; format sniffed from bytes, never trusted from names | Done (M3) |                                                                    | Error boundary does not report anywhere; worker errors are mapped to fixed messages (`toOpError`)                                                                                                                                                                                                                                                            | Done (M1)                          |
| Error reports leaking file names | Error boundary does not report anywhere; worker errors are mapped to fixed messages (`toOpError`) | Done (M1) |
| Saved signature exposure | Opt-in only, stored in this origin's IndexedDB, Forget button deletes it, never transmitted (CSP) | Done (M4) |
| Hostile form field names / values | Rendered as React text; field count capped at 2,000; values validated against field type and options | Done (M4) |
| Tampered or substituted OCR engine / language data | Fetched only from our origin, SHA-256 checked against hashes compiled into the app before use; CSP unchanged (no blob: scripts) | Done (M5) |
| Malicious scan images reaching the OCR engine | Pages are re-rendered by pdf.js to PNG first; one page at a time in a dedicated worker that is terminated on finish or cancel; 16 MP cap per page | Done (M5) |
| Malicious or stale code via the service worker | Same-origin GET only; precache list and version generated at build; never activates itself (update button disabled while busy); cached pages keep their CSP headers | Done (M6) |
| Release from an unreviewed tag | Release build in a `release` environment with required reviewers and a `main`-ancestry check; tag rulesets in docs/LAUNCH.md; refuses placeholder config | Done (M6, owner enables settings) |
| Analytics leaking data | Off by default; opt-in Cloudflare Web Analytics only, token kept out of the bundle, CSP widened to exactly its two hosts, disclosed on /privacy | Done (M6) |
| Zip-bomb image streams in Compress | Inflate capped at the declared image size | Done (M6) |
